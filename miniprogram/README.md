# 织见微信小程序演示版

这是与网页 Demo 使用同一组情境数据的原生微信小程序项目。账号名称拟设为“织见讨论”（后台显示可用，待上传头像并提交资料）；产品内入口是“产品方向讨论”，成员为孙宇杰、卢格妤、张轩灏。

## 打开方式

1. 在微信开发者工具中选择“导入项目”，目录选本文件夹 `miniprogram/`。
2. `project.config.json` 已配置织见小程序 AppID `wx557ddbcab0eefaaf`。在开发者工具中用具有该小程序开发者权限的微信账号登录。
3. 编译后在模拟器里进入“讨论 / 会议 / 决策”。真机预览和上传需要小程序账号、AppID 以及对应开发者权限。

小程序账号已使用 `zhijian@oppenheimer123.xyz` 注册。不要把登录验证码、AppSecret 或代码上传密钥提交到仓库。

开发版 `0.1.0` 已于 2026-10-08 上传成功。管理员可在小程序后台将其设为体验版，供体验成员扫码使用；对外发布仍需完成账号资料、类目、备案及平台审核。品牌头像位于 `images/avatar.png`，可用于后台资料提交。

## 已实现

- 群聊、会议发言、共享文件、机器人消息汇入一条按顺序排列的时间线；会议页可单独集中查看会议来源。
- 群聊文字消息、`@织见机器人` 演示回复、从微信会话选择文件；新增记录保存在当前设备的小程序本地存储。
- 开始/结束会议、手动记录会议发言，记录会回到同一条时间线。
- D-001 结构化决策，包含结论、负责人、期限、依据引用、反方意见和复核条件。
- 预览、复制及本地保存 Markdown/JSON 讨论上下文，保留时间、来源、发言人和决策出处。

## 当前边界

这是无需后端即可运行的交互演示。机器人回复由本地演示规则生成，并未调用模型 API；会议发言需要手动录入，没有自动录音或语音转写；文件仅记录名称，不上传、解析或跨设备同步。新增消息和保存文件只在当前设备内。正式用于团队协作时还需要身份、云端同步、文件存储、转写服务、模型服务及访问控制。
