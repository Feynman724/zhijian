# 织见第一版使用说明

访问地址：https://blog.oppenheimer123.xyz/zhijian/

## 1. 进入讨论空间

首页把群聊、线上会议和线下讨论放在同一个空间里。需要快速讨论时，可以点击“开始语音讨论”；转写内容会直接进入当前讨论，不用再手动搬运会议纪要。

点击消息下方的来源标签，可以回到对应的原始内容。

## 2. 查看讨论产出

页面右侧根据实际讨论显示三类产出：结论、行动项、分歧与依据。分工讨论会列出谁在什么时候前完成什么；出现争论时，会保留双方观点和各自依据。

点击左侧的“讨论产出”，可以集中查看已经确认的内容，也可以用顶部搜索框查找。

## 3. 在群聊中使用 AI

在底部输入框点击“@ 织见机器人”，然后输入问题。例如：

- 请整理当前已经形成的决策
- 还有哪些问题没有解决
- 请导出今天的完整上下文

机器人会直接在群聊时间线中回答，并附上引用来源。

## 4. 导出内容

点击右上角的“导出上下文”，可以选择 Markdown 或 JSON。导出内容包含时间、成员、来源、引用关系和结构化决策，可交给其他 AI 继续分析。

当前版本是交互 Demo。刷新页面后会恢复预置内容；“模型接入”用于展示配置方式，不会真正调用外部 API。
