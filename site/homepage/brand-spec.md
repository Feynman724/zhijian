# 织见主页品牌规范

- 品牌标记：复用产品 Demo 的三条声波 CSS 标记，不另造新图形。
- 产品画面：主页首屏直接嵌入团队版 Demo `/zhijian-team/`，避免使用与真实产品不一致的概念图。
- 主色：墨绿 `#284c43`；深墨绿 `#173a33`；浅绿 `#e4ece8`。
- 中性色：暖灰背景 `#e9e8e2`；纸白 `#fbfaf7`；文字 `#18211e`；次级文字 `#65706b`。
- 辅助色：铜色 `#8a6033` 表示证据与复核；灰紫 `#766b83` 表示会议来源。
- 字体：系统无衬线字体栈，与产品 Demo 一致。
- 圆角：控件 8–10px，内容卡片 14–18px，产品预览 20px。
- 阴影：只用于产品窗口和悬浮卡片，保持低对比度。
- 动效：200–500ms，使用淡入和轻微位移；尊重 `prefers-reduced-motion`。
